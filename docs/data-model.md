# Список данных МАТЭТИС

Этап 1 из [`plan.md`](plan.md). Это не схема таблиц, а перечень: какие данные есть, откуда берутся и кто их видит. Таблицы по этому списку создаются на следующих этапах, по одной группе за раз.

Основа — ТЗ ([`MATETIS_TZ_v3.docx`](MATETIS_TZ_v3.docx)) и [`architecture.md`](architecture.md).

## Кто есть в системе

- **Человек** — зарегистрированный пользователь.
- **Друг** — человек, с которым взаимно подтверждена дружба.
- **Другой человек** — любой зарегистрированный, но не друг.
- **Админ** — администратор (`admin`): ведёт доступы и оплаты, наполняет контент, видит учеников и статистику.
- **Контент-менеджер** (`content_manager`) — наполняет контент. Не видит учеников, доступы и оплаты.

Правила видимости проверяет сервер, а не только экран.

## 3а. Программа

Заполняет контент-менеджер или админ. Видят все, у кого есть доступ.

| Данные | Что внутри |
|---|---|
| Практика | Название; ежедневная (утро или вечер) или еженедельная; место в списке; текст; аудио (файл на диске сервера) или видео (ссылка на YouTube); с какого дня программы появляется у нового человека. Утро и вечер указываются у каждой ежедневной практики, чтобы новую было понятно куда ставить |
| Послание (раздел админки «Навигатор») | Имя Мастера; две части, в каждой: заголовок, текст и два задания — на первый и второй день части. Задания второй части по умолчанию повторяют задания первой (3-й день — как 1-й, 4-й — как 2-й), их можно поменять; объединяющее задание пятого дня; каким типам подходит (одно послание может быть у нескольких типов); порядок |
| Послание старцев (раздел «Навигатор») | Заголовок, текст, каким типам подходит, порядок. На 6-й и 7-й день недели навигатора. У каждого типа своя очередь, по кругу. Источник — «Печорские старцы», уточнится на примерах |
| Источник посланий | Один на все: «Книга Мудрости» Т.Н. Микушина. Задан в приложении, в базе не хранится |
| Осознания | Два вида, на экране оба: по книге «2 жизни» и на слабую стихию. В админке — вкладка «Осознания», устроены как практики |
| Варианты практики | Свой текст и видео: для каких типов (не отмечено — всем), для какой слабой стихии, на какую стихию года. Нет вариантов — текст практики видят все. Есть — человек видит подходящий; не подошёл ни один — практики у него нет. У практики галочка «Каждую неделю новый вариант»: варианты идут по порядку в те недели, когда практика есть в программе, потом по кругу |
| Слабая стихия человека | Пока Жанна не дала правило — стихия с наименьшим числом цифр по дате рождения, при равенстве — первая по кругу от Земли. Нет даты рождения — практик на слабую стихию нет |
| Приветственное видео | Ссылка на YouTube и текст, раздел админки «Библиотека». Не часть программы: объяснение подхода, показывается один раз перед первым входом в программу |
| Видео по стихии | Ссылка на YouTube и текст, для каждой стихии, раздел админки «Библиотека» |

**Чья практика:**

| Практика | Варианты | Как меняется |
|---|---|---|
| Медитация на качество силы | у каждого типа своя | новая каждый раз, когда она есть (раз в 2 недели) |
| Медитация на слабую стихию | у каждой слабой стихии своя | — |
| Прогулка без телефона | у каждого типа своя | каждую неделю новый вопрос |
| Полный цикл зарядки | одна для всех | на стихию |
| Осознание по книге «2 жизни» | у каждого типа своё | одно на стихию |
| Осознание на слабую стихию | у каждой слабой стихии своё | одно на стихию |

**Чередование медитаций с 15-го дня:** медитация на качество силы — в 3-ю, 5-ю, 7-ю… неделю программы, медитация на слабую стихию — в 4-ю, 6-ю, 8-ю… Недели программы считаются от первого дня человека: дни 1–7 — первая неделя.

**С какого дня программы появляется практика** у нового человека (по умолчанию, меняется в админке). «Мышление по навигатору» — обычная ежедневная практика, как внутренняя улыбка и линия души:

| Практика | День |
|---|---|
| Навигатор дня | 1 |
| Внутренняя улыбка | 1 |
| Мини-зарядка | 1 |
| Полный цикл зарядки | 1 |
| Медитация на качество силы | 1 |
| Видео по стихии | 1 |
| Осознание по книге «2 жизни» | 1 |
| Мышление по навигатору | 2 |
| Целительные звуки | 4 |
| Линия души | 8 |
| Медитация на слабую стихию | 8 |
| Осознание на слабую стихию | 8 |
| Прогулка без телефона | 15 |
| Медитации на качество силы и на слабую стихию чередуются по неделям | 15 |

Постепенное появление — только в первые две недели человека в программе. При смене стихии программа уже полная.

**Навигатор — одно послание на 7 дней** (ответ Жанны от 30 октября 2026):

| День | Текст | Задание |
|---|---|---|
| 1 | часть 1 | задание первого дня |
| 2 | часть 1 и «Прочитайте послание ещё раз и выполните новое задание» | задание второго дня, на карточке «Новое задание» |
| 3, 4 | часть 2 | так же |
| 5 | послание полностью, объединяющий день | задание пятого дня |
| 6 | послание старцев | как в 1-й день |
| 7 | то же послание старцев ещё раз | как во 2-й день, «Новое задание» |

Дни считаются от входа человека в приложение. Набор Мастеров и старцев у каждого типа свой; когда закончились — сначала, Жанна рассчитывает примерно на три круга. Нет послания старцев для типа — в 6-й и 7-й день карточки навигатора нет.

На карточке главного экрана — заголовок текущей части. Под текстом — строка «Источник», по нажатию снизу плашка с книгой и именем Мастера. Послания идут по порядку для типа человека; когда закончились — сначала.

**Приветственное видео** открывается само перед первым входом в программу и после «Просмотрено» больше не появляется. Если человек закрыл его, не досмотрев, оно откроется при следующем входе.

**Видео по стихии** стоит в «На этой неделе», пока человек его не посмотрит, потом переезжает вниз программы.

| Данные | Откуда | Видит сам | Друг | Другой | Админ |

| Отметка выполнения: практика, дата | Человек нажимает букву «МАТЭТИС» | да | нет | нет | да |
| Участие в периоде стихии: с какого дня человек в программе | Создаётся при первом входе в период | да | нет | нет | да |

| Начало программы: первый день человека | Первый вход в программу. Один раз, от него считаются день программы и день навигатора. Дни — по часам телефона человека, пока телефон их не сообщил — по Минску | да | нет | нет | да |
| «Прочитано» послание: послание, день | Кнопка «Прочитано» на экране навигатора | да | нет | нет | да |
| Заметка к «Мышлению по навигатору»: текст, день | По желанию, на вечернем экране | да | нет | нет | нет |
| Просмотрено приветственное видео: когда | Кнопка «Просмотрено» | да | нет | нет | да |
| Просмотрено видео по стихии: стихия, год | Кнопка на карточке видео | да | нет | нет | да |

Процент для бейджа считается с первого дня человека в программе этой стихии, а не с начала стихии.

Правила отметок из ТЗ: одна отметка на практику в день, повторная не считается. Пропуски не хранятся — это просто отсутствие отметки. История не удаляется при смене недели или стихии.

Счётчики профиля (сколько практик выполнено, процент за неделю, история стихий) не хранятся отдельно — считаются из отметок.

## 7. Доступ по подписке

Бесплатны вход, онбординг, тест и результат теста. Остальное — только с доступом. У админа и контент-менеджера доступ есть всегда. Видит и меняет только админ; сам человек видит свой статус и дату окончания.

| Данные | Откуда |
|---|---|
| Период доступа: почта, с какого момента и по какой, сумма и валюта, способ оплаты (пока «вручную»), кто добавил и когда | Админ открывает или продлевает доступ. Каждое продление — отдельная запись, при закрытии доступа записи не удаляются. Связь с человеком — по почте или нику в Telegram (у кого ника нет — по номеру в Telegram): доступ можно открыть до регистрации. Сменил ник — доступ переезжает на новый при следующем входе |
| Статус: заявка, до даты, скоро закончится (3 дня и меньше), закончился | Не хранится — считается из периодов. «Заявка» — человек прошёл тест, а доступ ещё не открывали |
| Настройки доступа: телефон и ник Telegram администратора, цены первого месяца, месяца и трёх месяцев | Админка. Телефон видит каждый, кому нужен доступ; ник на экране не показывается, по нему Telegram открывает чат с готовым сообщением |

Уведомления администратору на телефон: о заявке — сразу, о скором окончании доступа — одна сводка в день в 10:00 по Минску. В тексте только имя человека или число людей, без почты и ника.

| Данные | Откуда |
|---|---|
| Устройство для уведомлений: адрес службы уведомлений браузера и ключи | Админ нажимает «Включить уведомления». Человек разрешает уведомления в профиле или на экране программы — для фразы дня |
| Кто уже был в сводке: почта или ник и дата окончания доступа на тот момент | Сервер при отправке сводки. После продления человек попадёт в сводку снова |

## 8. Статистика админа

Отдельно не хранится. Все цифры — регистрации, распределение по типам, активные, выполнение практик и ритуалов, данные по ученику — считаются из таблиц выше. Админ видит их через отдельные запросы, к которым у обычного человека нет доступа.
