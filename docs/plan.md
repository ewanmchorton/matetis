# План разработки MVP

Принят 14 октября 2026. Каждый этап ведём в отдельном чате. Следующий этап начинаем только после того, как текущий проверен.

Тест и программа зависят от материалов Жанны (Мастера). Ответ ожидается до конца недели 14–18 октября, поэтому эти этапы стоят после профиля и друзей.

| № | Этап | Что получится | Статус |
|---|---|---|---|
| 1 | Список данных | Документ `docs/data-model.md`: какие данные есть в приложении и кто их видит. Код не пишется | **Текущий** |
| 2 | Вход и регистрация | Человек создаёт аккаунт, имя и согласие сохраняются в базе. Первая часть — [`tasks/01-person-card.md`](tasks/01-person-card.md) | |
| 3 | Профиль и друзья | Найти человека, открыть его профиль, запрос в друзья, настройки публикации событий | |
| 4 | Тест и тип | Результат теста и дата рождения сохраняются за человеком. Ждёт Жанну | |
| 5 | Программа и отметки | Админ наполняет программу «тип + стихия», человек видит её и отмечает выполнение. Ждёт Жанну | |
| 6 | Статистика профиля и бейджи | Личный прогресс, бейдж стихии за 70% | |
| 7 | Совместные практики и лента | Приглашения, совместная практика, лента событий, реакции, автоподбор раз в месяц | |
| 8 | Библиотека | Каталог практик, загрузка книг и сканов, видео | |
| 9 | Админка целиком | Статистика, редактирование теста и 12 типов | |
| 10 | Подготовка к тестовой группе | Своя почта для писем, резервные копии базы, публикация | |

Дизайн подключаем по ходу, когда будут макеты. На порядок этапов он не влияет.

## Почему такой порядок

- Список данных нужен до первой таблицы, чтобы таблицы потом не переделывать.
- Статистика профиля и совместные практики зависят от практик и отметок. Поэтому до ответа Жанны делаем только ту часть профиля и «Вместе», что от практик не зависит: друзей и настройки.

При переходе к следующему этапу обнови столбец «Статус» в этом файле.
