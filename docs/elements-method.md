# Методика: стихии по дате рождения

Материал Жанны (Мастер) от 19 октября 2026. Расчёт в коде: `src/entities/birth-reading/model/calculate.ts`.

Пользователю результат пока не показывается. По нему будут подбираться медитации и практики на сильные и слабые стихии.

## 1. Квадрат Пифагора

1. Выписываем цифры даты рождения (ДД.ММ.ГГГГ).
2. Считаем четыре рабочих числа:
   - **первое** — сумма всех цифр даты;
   - **второе** — сумма цифр первого числа (один раз, к одной цифре не сводим);
   - **третье** — первое число минус удвоенная первая цифра дня рождения. Для дней 01–09 берём саму цифру дня, ноль не считается;
   - **четвёртое** — сумма цифр третьего числа.
3. Складываем цифры даты и цифры рабочих чисел и считаем, сколько раз встречается каждая цифра 1–9. Нули не учитываются.

Для родившихся после 2000 года расчёт тот же. Если третье число получилось отрицательным (например, 09.01.2000: 12 − 18 = −6), минус не считается цифрой.

## 2. Цифры по стихиям

Инь и ян не учитываем, считаем только количество цифр.

| Стихия | Цифры |
|---|---|
| Земля | 2, 5, 8 |
| Металл | 6, 7 |
| Вода | 1 |
| Дерево | 3, 4 |
| Огонь | 9 |

Стихии показываем в порядке круга Усин, начиная с Земли: Земля → Металл → Вода → Дерево → Огонь. Круг нужен только для наглядности и в расчёте не участвует.

## 3. Оценка по количеству цифр

| Количество | Оценка |
|---|---|
| 0 | отсутствует |
| 1 | наличие |
| 2 | баланс |
| 3 | разбалансирована |
| 4 | сильная |
| 5 | очень сильная, может стать разрушительной |
| 6 и больше | перегрузка |

## Пример: 15.03.1988

- Рабочие числа: 35, 8, 33, 6.
- Цифры: 1 — 2 раза, 3 — 4, 5 — 2, 6 — 1, 8 — 3, 9 — 1; 2, 4 и 7 нет.
- Стихии: Земля 5 (очень сильная), Металл 1 (наличие), Вода 2 (баланс), Дерево 4 (сильная), Огонь 1 (наличие).

## Значения цифр

Из материала Жанны. В приложении пока не используются.

| Цифра | Значение |

| 8 | Долг земных уз |
