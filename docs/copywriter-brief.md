# ТЗ для копирайтера

Сюда собираем задачи для копирайтера по мере разработки. Каждая задача – отдельный раздел: что нужно написать, где текст стоит в приложении, какие тексты есть сейчас.

## Общие правила

- Название приложения – **МАТЭТИС**, через «Э».
- Тире только среднее «–» с пробелами по бокам. Длинное «—» не используем.
- Тон спокойный и тёплый, без соревнования, цифр и «достижений». Человек не гонится за результатом – он идёт своим путём.

## 1. Экраны спутника «Гармония» по стихиям

**Что это.** У каждого человека есть спутник – персонаж «Гармония». Пока человек проходит программу стихии, спутник растёт: 6 состояний. Когда спутник переходит в новое состояние, открывается экран превращения. Когда начинается новая стихия, спутник возвращается в первое состояние и открывается экран «Новая стихия».

Стихий пять: Дерево, Огонь, Земля, Металл, Вода. Сейчас тексты одни на все стихии. Нужно посмотреть текущие и написать свой набор для каждой стихии, чтобы в нём чувствовался её характер.

**Как устроен экран** (макеты `design/screens/07_transition.PNG` и `07_new period.PNG`):

1. Подпись над заголовком, мелко, заглавными буквами: «Гармония · Соединение».
2. Заголовок – крупный шрифт с засечками, не длиннее двух строк, примерно до 40 знаков.
3. Текст – две короткие строки, примерно до 90 знаков.
4. Кнопка «Дальше».

Состояния: 1. Пробуждение, 2. Раскрытие, 3. Течение, 4. Соединение, 5. Расцвет, 6. Пробуждение (круг замыкается – отсылка к пробуждению в духовном смысле).

**Текущие тексты превращения** (одни на все стихии):

| Состояние | Заголовок | Текст |
|---|---|---|
| 2. Раскрытие | Что-то внутри начинает раскрываться | Твой спутник меняется вместе с тобой. Гармония переходит в Раскрытие. |
| 3. Течение | Всё приходит в движение | Твой спутник меняется вместе с тобой. Гармония переходит в Течение. |
| 4. Соединение | Всё соединяется внутри тебя | Твой спутник меняется вместе с тобой. Гармония переходит в Соединение. |
| 5. Расцвет | Всё, что ты растил, расцветает | Твой спутник меняется вместе с тобой. Гармония переходит в Расцвет. |
| 6. Пробуждение | Пройдя путь, возвращаешься к истоку | Твой спутник меняется вместе с тобой. Гармония переходит в Пробуждение. |

**Текущий текст экрана «Новая стихия»:**

| Подпись | Заголовок | Текст |
|---|---|---|
| Стихия Металл | Новый виток твоего пути | Гармония снова в Пробуждении. Начинаем новый цикл вместе. |

**Что нужно.** Для каждой из пяти стихий: заголовок и текст для состояний 2–6 и для экрана «Новая стихия». Итого 30 пар «заголовок + текст». Подпись над заголовком не меняется.
