# Архитектура МАТЭТИС

Принято 15 октября 2026.

Не предлагай другой хостинг, базу или хранилище файлов без явной просьбы.

## Из чего состоит

Один виртуальный сервер (VDS) в России. На нём через Docker Compose работают:

| Часть | Что делает |
|---|---|
| Приложение | Next.js с серверной частью: экраны, вход и все правила приложения |
| База PostgreSQL | Данные приложения. Хранится в Docker-вольюме |
| Файлы | Книги, PDF, картинки, фоны, аудио. Хранятся на диске сервера в Docker-вольюме. Картинки загружаются в готовом размере, сервер их не сжимает (решение от 28 октября 2026) |
| Копирование базы | Каждую ночь сохраняет копию базы за пределы сервера |
| Caddy | Принимает запросы из интернета, сам получает и продлевает сертификат HTTPS |

Вне сервера:

| Задача | Где |
|---|---|
| Копии базы | S3-хранилище российского провайдера |
| Видео | YouTube |
| Письма (регистрация, сброс пароля) | Российский сервис рассылок |

Аудитория: в первую очередь Беларусь, затем Россия. Нагрузка: до 50 человек на старте, до 1000 в первый год.

## Код

- PWA на Next.js с серверной частью. Структура по FSD.
- Все правила проверяет сервер, а не телефон. Дату рождения, тип и расчёт по дате рождения видят только сам человек и администратор.
- Вход и регистрация — библиотека Better Auth. Учётные записи хранятся в нашей базе.
- Работа с базой — Drizzle. Каждое изменение базы — отдельный файл-миграция в Git.
- Приложение собирается на GitHub, на сервер отправляется готовым.

## Резервные копии

- Каждую ночь, хранятся не меньше 14 дней.
- Хранятся в S3-хранилище, а не на диске сервера.
- Раз в месяц проверяем восстановление из копии.

## Разработка и запуск

- Разработка идёт на компьютере разработчика в Docker: приложение, база и локальный почтовый ящик для писем.
- Сервер арендуется перед тестовой группой. Тот же `docker-compose.yml` запускается у любого провайдера.
- Провайдер выбирается перед арендой. Кандидаты: Timeweb Cloud, VDSka, Selectel, Beget.
- Минимальный сервер: 1 vCPU, 2 ГБ памяти, 15–20 ГБ SSD, KVM, дата-центр в России.

## До тестовой группы

- Арендовать сервер, подключить домен и S3-хранилище для копий базы.
- Подключить сервис рассылок.
- Настроить ночные копии и проверить восстановление.
- Уведомить Роскомнадзор об обработке персональных данных и опубликовать политику обработки данных.

## Что не делаем в MVP

- Управляемую базу у провайдера: хватает базы в Docker.
- Офлайн-режим: отметки работают только при наличии интернета.
- Kubernetes и несколько серверов.
