# МАТЭТИС — мобильный прототип (шаг 1)

Мобильное приложение для учеников Мастера (Жанны): тест определяет один из 12 типов,
а дальше приложение будет выдавать программу практик под связку «тип + текущая стихия».

Прототип делаем **по шагам, только для телефона**. Сейчас готов **шаг 1 — первый вход**:

1. Регистрация (`/auth`, есть и вкладка «Вход»)
2. Онбординг — 3 экрана знакомства (`/onboarding`)
3. Тест на тип (`/test` — по шагам, `/test?variant=page` — одной страницей)
4. Результат теста (`/test/result`)

Тексты теста — настоящие, из черновиков Мастера (две группы описаний, тип = буква + цифра).
Сервера нет: данные выдуманные, результат теста хранится в браузере (localStorage).
На компьютере приложение показывается узкой колонкой ~390 px по центру, как на телефоне.

## Как запустить

Нужны Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev          # http://localhost:4317 (сразу откроется регистрация)
```

- `pnpm dev` — дев-сервер на порту 4317
- `pnpm typecheck` — проверка типов TypeScript
- `pnpm lint` — проверка кода ESLint
- `pnpm build` — production-сборка

## Стек и структура

Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui (на Base UI), иконки lucide.
Код разложен по Feature-Sliced Design:

```
src/
  app/        маршруты Next.js — тонкие обёртки, только подключают экран
  views/      экраны целиком: регистрация, онбординг, тест, результат
  features/   действия пользователя: пройти тест
  entities/   сущности: стихия, тип, тест, прогресс ученика
  shared/     общее: UI-компоненты, адреса экранов, утилиты
```

Тестовые данные лежат в `src/entities/*/api/*-api.ts`. Когда появится сервер,
заменяются только эти функции — экраны останутся прежними.

Правила для разработки и ИИ-агентов — в [`AGENTS.md`](./AGENTS.md).
