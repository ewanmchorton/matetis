# МАТЭТИС — мобильный прототип (шаги 1–2)

Мобильное приложение для учеников Мастера (Жанны): тест определяет один из 12 типов,
а дальше приложение выдаёт программу практик под связку «тип + текущая стихия».

Прототип делаем **по шагам, только для телефона**.

**Шаг 1 — первый вход:**

1. Регистрация (`/auth`, есть и вкладка «Вход»)
2. Онбординг — 3 экрана знакомства (`/onboarding`)
3. Тест на тип (`/test` — по шагам, `/test?variant=page` — одной страницей)
4. Результат теста (`/test/result`) → кнопка «Перейти к программе»

**Шаг 2 — главная «Программа»** (`/program`), с нижним меню «Программа / Библиотека / Профиль».
Контент прототипа сейчас собран под **стихию Воды** (запуск — 1 декабря):


- Практика сегодня — одна практика дня и кнопка «Выполнено»
- Еженедельные ритуалы — отметка галочкой за сегодня, счётчик «2 из 5» за неделю
- Рекомендации стихии — видео Мастера, книги, фильмы
- Статистика — дни подряд и сколько практик выполнено
- Библиотека (`/library`) и Профиль (`/profile`) — пока заглушки «Скоро»

Тексты теста — настоящие, из черновиков Мастера (две группы описаний, тип = буква + цифра).
Сервера нет: данные выдуманные, результат теста и отметки практик хранятся в браузере
(localStorage). Чтобы статистика не была пустой, в ней заранее «выполнено» несколько прошлых дней.
На компьютере приложение показывается узкой колонкой ~390 px по центру, как на телефоне.

## Как запустить

Нужны Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev          # http://localhost:4317 (сразу откроется регистрация)
```

- `pnpm dev` — дев-сервер на порту 4317
- `pnpm typecheck` — проверка типов TypeScript
- `pnpm lint` — проверка кода ESLint
- `pnpm build` — production-сборка

## Стек и структура

Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui (на Base UI), иконки lucide.
Код разложен по Feature-Sliced Design:

```
src/
  app/        маршруты Next.js — тонкие обёртки, только подключают экран
              (tabs)/ — вкладки с нижним меню: программа, библиотека, профиль
  views/      экраны целиком: регистрация, онбординг, тест, результат, программа
  widgets/    крупные блоки интерфейса: нижнее меню
  features/   действия пользователя: пройти тест
  entities/   сущности: стихия, тип, тест, практики и ритуалы, прогресс ученика
  shared/     общее: UI-компоненты, адреса экранов, утилиты
```

Тестовые данные лежат в `src/entities/*/api/*-api.ts`. Когда появится сервер,
заменяются только эти функции — экраны останутся прежними.

Правила для разработки и ИИ-агентов — в [`AGENTS.md`](./AGENTS.md).
