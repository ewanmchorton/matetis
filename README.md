# МАТЕТИС — мобильный прототип

Название в коде: `APP_NAME` в `src/shared/config/brand.ts`.

Мобильное приложение: тест определяет один из 12 психотипов, дальше — программа практик
под связку «тип + текущая стихия» (даосская пятёрка).

Прототип **только для телефона**, без сервера, данные в браузере (localStorage).

**Шаг 1 — первый вход:** регистрация → онбординг → тест → результат.

**Шаг 2 — программа и вкладки:**

- **Программа** — практика дня, еженедельные ритуалы, рекомендации стихии, мягкая отсылка к статистике в профиле
- **Библиотека** — видео, медитации, книги и фильмы (сейчас контент стихии **Воды**, запуск 1 декабря)
- **Профиль** — тип, аккаунт (демо), статистика, ритуалы, напоминания (демо)

**Админка (веб-версия)** — `/admin`, на всю ширину экрана компьютера:

- **Обзор** — текущая стихия и счётчики
- **Материалы** — добавить/удалить видео, медитацию, книгу, фильм (стихия по желанию, файл с компьютера)
- **Практики и ритуалы** — практики дня и ритуалы (раз в неделю или с отметками по дням)
- **Ученики** — демо-список

Что добавлено в админке, сразу видно в приложении (в том же браузере): материалы — в библиотеке,
практики и ритуалы — на экране программы. Файлы в демо не загружаются, сохраняется только имя.
Кнопка «Сбросить демо-данные» возвращает исходное наполнение.

Меню **«Экраны»** сверху справа — карта прототипа для разработки.

## Как запустить

Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev          # http://localhost:4317
```

- `pnpm typecheck` · `pnpm lint` · `pnpm build`

## База и вход (локально)

Нужен Docker (на Mac — OrbStack).

```bash
cp .env.example .env.local   # затем впишите BETTER_AUTH_SECRET: openssl rand -base64 32
pnpm db:up                   # база PostgreSQL и почтовый ящик Mailpit (http://localhost:8025)
pnpm db:migrate              # применить миграции из папки drizzle/
```

- Таблицы описаны в `src/shared/db/schema/`. После их изменения: `pnpm db:generate`, затем `pnpm db:migrate`.
- Вход и регистрация — Better Auth, адрес `/api/auth/*`, настройки в `src/shared/auth/server.ts`.
- Назначить админа можно только запросом в базу:
  `docker compose exec db psql -U matetis -d matetis -c "update \"user\" set role = 'admin' where email = '...'"`.
- На GitHub Pages публикуются только экраны прототипа, без серверной части.

## Структура (FSD)

```
src/
  app/          маршруты Next.js: (mobile)/ — экраны в рамке телефона, admin/ — веб-админка
  views/        экраны
  widgets/      нижнее меню, рамка телефона, оболочка админки, навигация по прототипу
  features/     прохождение теста, добавление материалов и практик
  entities/     тип, стихия, практики, библиотека, ученики, прогресс
  shared/       UI, маршруты, утилиты
```

Демо-данные в `entities/*/api/*-api.ts`. Правила для агентов — [`AGENTS.md`](./AGENTS.md).
