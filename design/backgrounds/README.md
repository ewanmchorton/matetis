Фоны превращения сменяют друг друга от состояния к состоянию: Раскрытие – занавеси, Течение – лестница, Соединение – дорожка, дальше по кругу.

Фоны Дерева, Огня, Земли и Металла для библиотеки сюда не кладём: их загрузит контент-менеджер в админке. В прототипе из стихий лежит только Вода.

## Спутник

Картинки персонажа – в `design/character`: `stage 1–6.PNG` в полный рост и `ava 1–6.PNG` для кружков. В приложение их переносит `bash scripts/build-character.sh` (в `public/character`). Если кружка нет, скрипт вырезает его из `stage N`.
